Har laget ein kode som teste om ein stack kan legge til data, holde på den og see den. Har og testet om det er mulig og legge til informasjon utenfor stacken.

Test 1 tester om push og pop fungerer

Test 2 tester om vi kan sende data fra utsiden av stacken til å legge til data

Test 3 Tester at ein tom stack sender ein error

Test 4 Tester at ein stack ikkje kan ha null verdi

Test 5 Tester at stacken kan ta imot data og lagre den, og at dataen kan bli lest 

For å teste trengs disse kommandoene

cd TestsappFolder
dotnet test
